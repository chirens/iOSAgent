# iOSAgent 云编译上手指南（Windows 零 Mac 方案）

## 核心结论
- Windows **无法**直接编译 iOS App（iOS SDK / Xcode / codesign 只在 macOS）。
- 但你手机上的签名 App（Feather / ESign / AltStore / SideStore）负责「签名 + 安装」。
- 缺的只是「源码 → IPA」这一步，用 **GitHub Actions 免费 macOS Runner（云 Mac）** 完成。
- 本工作流产出的是**未签名 IPA**，你下载后用手机证书重签安装。CI 里**不碰你的证书**，零泄露。

## 一、准备 GitHub 仓库（公共仓库 = 免费 macOS 分钟）
1. 打开 https://github.com/new
2. Repository name 随意，例如 `iOSAgent`
3. 选 **Public**（private 也行，但免费额度少，按 ~10× Linux 计费）
4. 不要勾 Initialize（保持空仓库）

## 二、把工程推上去
你本地（Windows）用 Git 把 `iOSAgent/` 目录里的内容推到仓库根：

```bash
cd iOSAgent
git init
git add .
git commit -m "init iOSAgent"
git branch -M main
git remote add origin https://github.com/<你的用户名>/iOSAgent.git
git push -u origin main
```

注意：`.gitignore` 不需要特别处理，项目里没有证书/密钥文件，API Key 存在 AppStorage 不入库，安全。

## 三、一键云编译出 IPA
1. 进仓库 → 顶部 **Actions** 标签
2. 左侧选 `Build iOSAgent IPA (unsigned)`
3. 右侧 **Run workflow** → 确认分支 main → 点 Run
4. 等待 2–5 分钟（首次 Xcode 环境拉起略慢）
5. 完成后进该次 run → 底部 **Artifacts** → 下载 `iOSAgent-unsigned`

产物是 `iOSAgent-unsigned.ipa`（未签名）。如果 build 失败，点开 run 看红色日志，把报错发我，我在这边改源码后你重新 Run。

## 四、手机上签名并安装
用你已有的签名 App（Feather / ESign / Scarlet / SideStore 任一）：
1. 把 `iOSAgent-unsigned.ipa` 传到手机（AirDrop / 网盘 / 微信文件）
2. 用签名 App 打开它 → 导入你的 **.p12 证书 + .mobileprovision 描述文件**
3. 点「签名」→「安装」
4. 首次打开若提示「未受信任」，去 设置 → 通用 → VPN与设备管理 → 信任你的证书

### 证书说明
- **免费 Apple ID 自签**：用你日常 Apple ID 在签名 App 里生成 personal 描述文件即可，7 天有效期，到期用 Feather 一键重签。适合自用测试。
- **$99 开发者证书**：长期稳定（1 年），适合小圈子分发。现阶段自测用免费的就够。

## 五、使用
1. 打开 iOSAgent → 切到「设置」标签
2. 填：Base URL（如 `https://api.openai.com/v1` 或你自己的兼容端点）、API Key、模型名（如 `gpt-4o-mini`）
3. 「测试连接」验证能通
4. 回「对话」标签：输入问题，或点左下相册图标附一张截图（截图需你先在系统/快捷指令截好进相册），让云端模型识别屏幕内容并给操作建议
5. 动手触发别家 App：在对话里让模型给出 URL Scheme，或用「快捷指令」调用本 App 暴露的 `打开App` / `询问Agent` 意图

## 六、改代码后如何重出包
1. 在 Windows 改完 `iOSAgent/` 下任意 Swift 文件
2. `git add . && git commit -m "..." && git push`
3. push 到 main 会自动触发编译；或在 Actions 手动 Run workflow
4. 重新下载 IPA、重签、安装

## 七、常见问题
- **编译报 scheme / target 找不到**：工作流用的是 `-target iOSAgent`，工程里已正确定义，正常不会出现。
- **报签名相关错误**：不会，因为 `CODE_SIGNING_ALLOWED=NO` 完全跳过签名，签名留给手机端。
- **装不上 / 打开闪退**：多半是描述文件没包含本机 UDID 或 bundle id 冲突。用签名 App 重新生成描述文件（bundle id 保持 `com.chen.iOSAgent`）再签。
- **想换 bundle id**：改 `iOSAgent.xcodeproj/project.pbxproj` 里两处 `PRODUCT_BUNDLE_IDENTIFIER` 即可。
